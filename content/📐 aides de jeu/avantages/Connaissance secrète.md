Le personnage possède une connaissance dans certains domaines, dont peu de personnes disposent. Pour toutes les connaissances d’un type au choix parmi : pègre, occulte, secte, société secrète…, lorsque le personnage effectue un jet base Savoir, le niveau de difficulté (pas le score) est abaissé de un. Cet avantage fonctionne tout le temps pour le type de connaissance choisi.
