Le personnage possède une connaissance le domaine de l'occulte, dont peu de personnes disposent. Pour toutes les connaissances "**occulte**", lorsque le personnage effectue un jet base **Savoir**, le niveau de difficulté (pas le score) est abaissé de un. Cet avantage fonctionne tout le temps pour le type de connaissance choisi.
