# 🧩 Aide de Jeu MJ

## Bandes

- **Attaque de bande sur les PJ** : dégâts automatiques = débordement × tours écoulés (pas de jet).
- L'OD d'Endurance niv. 5 soustrait l'Endurance du chevalier à chaque application du débordement.

## Matériel

- **Casser une arme** (test base Force, ou Chair pour un PNJ) :
	- Arme standard : difficulté **ardue (5)**
	- Arme avancée : difficulté **complexe (7)**
	- Arme rare : difficulté **insurmontable (12)**
	- Idem pour casser les modules de combat.
- **Réparer** : hors combat, sans aide ni outil, test difficulté **9** pour rendre 1D6 PA à une méta-armure ou un véhicule. Impossible pendant une phase de conflit.

## Tests

- **Succès excédentaires** : ils ne servent à rien par eux-mêmes (sauf effets type *assistance à l'attaque*) ; le MJ peut toujours majorer les conséquences d'un test particulièrement bien réussi.
