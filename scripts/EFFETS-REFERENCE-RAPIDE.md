# Effets — référence rapide

Cette table est destinée aux fiches utilisées en partie. Les notes d’effets
continuent d’utiliser les descriptions officielles complètes de
`effect-catalog.json`.

Les effets `Ignore armure`, `Ignore CdF` et `Deux mains` sont considérés comme
autosuffisants : leur nom reste affiché sur les armes, mais ils ne sont pas
répétés dans la section imprimée `Rappels d’effets`.

| Effet | Description rapide |
|---|---|
| Anathème | Peut infliger les dégâts aux PE plutôt qu’aux PS. Le CdF s’applique, pas les PA. |
| Anti-véhicule | Dégâts normaux contre les véhicules et colosses, sans conversion par tranches de 10. |
| Assistance à l’attaque | +1 dégât (ou violence) par réussite excédentaire au-dessus de la Défense ou Réaction cible. |
| Barrage X | À la place d’une attaque : Défense et Réaction de la cible −X jusqu’au prochain tour de l’attaquant. Automatique et cumulable. |
| Chargeur X | Utilisable X fois avant épuisement. Rechargement gratuit entre deux missions. |
| Choc X | Si le jet d’attaque dépasse Chair/2 de la cible : elle perd X action(s). Sans effet sur les bandes ; non cumulable. |
| Défense X | +X Défense tant que l’équipement est utilisé. Cumulable. |
| Dégâts continus X | X dégâts au début de chaque tour de la cible pendant 1D6 tours ; ignore CdF et bouclier. Non cumulable. |
| Désignation | 1 cible par tour, sans action : +1 réussite automatique pour l’attaquer et aucun échec critique. Dure toute la scène. |
| Destructeur | +2D6 dégâts si au moins 1 dégât atteint les PA. |
| Deux mains | Nécessite les deux mains. |
| Dispersion X | Une attaque peut toucher jusqu’à X cibles séparées de 2 m maximum. Les cibles secondaires sont touchées si le jet dépasse leur opposition. |
| En chaîne | Après avoir neutralisé un hostile ou salopard : 3 PE pour attaquer immédiatement une autre cible valide. Répétable. |
| Fureur | +4D6 Violence contre une bande ayant Chair 10 ou plus. |
| Ignore armure | Ignore les PA ; les dégâts affectent directement les PS après CdF ou bouclier. |
| Ignore CdF | Ignore le CdF ; les dégâts affectent directement les PS après PA ou bouclier. |
| Jumelé (akimbo) | Avec deux exemplaires en akimbo : seulement 1D6 de malus au lieu de 3D6. |
| Jumelé (ambidextrie) | Avec deux armes compatibles en ambidextrie : seulement 1D6 de malus au lieu de 3D6. |
| Lesté | Ajoute Force ×2 aux dégâts au lieu de Force ; pour un PNJ, ajoute Chair entier au lieu de Chair/2. |
| Lourd | Chaque utilisation coûte 1 action de déplacement et 1 action de combat. |
| Lumière X | Contre l’Anathème : Défense et Réaction −X jusqu’à la fin du prochain tour de l’attaquant. Non cumulable. |
| Meurtrier | +2D6 dégâts si au moins 1 dégât atteint les PS. |
| Oblitération | Contre un hostile, chaque dé de dégâts vaut automatiquement 6. |
| Orfèvrerie | Ajoute Dextérité + OD aux dégâts ; pour un PNJ, ajoute Masque/2 arrondi au supérieur. |
| Parasitage X | Cible technologique ou de la Machine : perd X action(s). Non cumulable avec Choc. |
| Pénétrant X | Ignore X points de CdF ; si X atteint le CdF total, celui-ci est entièrement ignoré. Sans effet sur le bouclier. |
| Perce armure X | Ignore X PA ; si X atteint les PA totaux, l’armure est entièrement ignorée. |
| Précision | Ajoute Tir + OD aux dégâts ; pour un PNJ, ajoute Machine/2 arrondi au supérieur. |
| Silencieux | En attaque surprise ou invisible, ajoute Discrétion aux dégâts ; PNJ : Masque/2 + AE. |
| Tir en sécurité | Permet de tirer à couvert sans subir le malus au tir du style à couvert. |
| Ultraviolence | +2D6 Violence contre une bande ayant Chair inférieur à 10. |

`X` est remplacé dans les fiches par la valeur portée par l’arme ou la capacité.
